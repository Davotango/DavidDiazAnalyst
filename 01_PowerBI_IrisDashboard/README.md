# Power BI — Flower Species Dashboard

Interactive dashboard to classify three Iris species 
(Setosa, Versicolor, Virginica) using petal and sepal 
measurements across 150 samples.

## Tools Used
- Power BI
- Iris Dataset (150 records)

## Key Insights
- Setosa is clearly separable from the other two species
- Virginica has the largest average measurements overall
- Versicolor sits distinctly between the two
